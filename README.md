# HRM Suite - Human Resource Management Dashboard

A premium, fully functional HR management system built with React 19, Bootstrap 5, and Vite.

## ✨ Features
- **Dashboard**: Real-time KPIs and interactive charts.
- **Employees**: Full CRUD for employee records.
- **Recruitment**: Manage jobs and candidate hiring pipeline.
- **Attendance**: Track daily check-ins and check-outs.
- **Payroll**: Process salaries and track payment history.
- **Leaves**: Modern leave application and approval workflow.
- **Performance**: Monitor scores and reviews.
- **Training**: Manage upskilling programs.

## 🚀 Setup & Installation
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
